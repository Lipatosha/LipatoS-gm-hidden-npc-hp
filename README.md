# LipatoS - Скрытие лечения NPC

Модуль для **Foundry Virtual Tabletop**, который скрывает от игроков всплывающие цифры восстановления HP у NPC, но оставляет видимыми цифры полученного NPC урона.

## Версия

**2.0.0**

## Что делает модуль

- игроки видят урон по NPC как обычно;
- игроки не видят всплывающие цифры лечения и восстановления HP у NPC;
- ГМ и Assistant GM видят и урон, и лечение без ограничений;
- значения HP и механика боя не изменяются;
- скрывается только визуальная всплывающая цифра положительного изменения HP рядом с NPC.

## Совместимость

- Foundry VTT: **14**

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте ссылку на манифест:

`https://raw.githubusercontent.com/Lipatosha/LipatoS-gm-hidden-npc-hp/main/module.json`
